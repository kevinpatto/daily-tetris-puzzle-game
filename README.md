# Daily Game, by Kevin Patto

## Frontend implementation branch

This branch is for implementing the general frontend structure of the website. This branch will be closed when a sufficient version is produced, and will be branched from when relatively significant features need to be implemented.

## Branches from this branch

### Specific user URLS

This branch will implement user-specific URLS for each user. For example, a user named "john" will have the url "./accounts/john" for their user profile, or a user named "frederick" will have the url "./accounts/frederick" for their user profile. A user that is logged in will be able to click a button with their username in the header that will direct them to their own account. For now, a user will have to type another user's username directly into the url to view their profile. However, in the future there will be ways to view others' profiles through navigation, such as in a leaderboard or in a friends list.
